# 🧮 Neon Calculator (Python + Tkinter)

A modern, aesthetic calculator built using Python and Tkinter with a neon-style UI, history tracking, and scientific functions.

---

## 🚀 Features

- ✨ Neon-themed UI (dark + glowing accents)
- 🧠 Basic operations (+, -, ×, ÷)
- 📜 Calculation history
- 🔬 Scientific mode:
  - Logarithm (log)
  - Antilog
  - Square root
- ⌨️ Keyboard support
- 🎨 Hover button animations
